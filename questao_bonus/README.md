# Questao Bonus - LRU e comparacao com FIFO

## Executar

Abra o terminal nesta pasta e execute:

```powershell
javac QuestaoBonus.java
java QuestaoBonus
```

Quando solicitado, informe 3 frames e a sequencia:

```text
7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2
```

## Resultado

Com a entrada de exemplo: FIFO com 10 faltas e LRU com 9 faltas.
