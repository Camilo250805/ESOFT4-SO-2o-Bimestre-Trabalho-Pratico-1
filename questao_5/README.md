# Questao 5 - Comparacao de desempenho entre pilha e heap

## Executar

Abra o terminal nesta pasta e execute:

```powershell
gcc -std=c11 -O2 -Wall -Wextra -Wpedantic questao5.c -o questao5.exe
.\questao5.exe
```

## Resultado

Sete rodadas de 1.000.000 de operacoes por teste; medias e diferenca percentual. Tempos variam.

A saida real do teste esta em [resultado_execucao.txt](resultado_execucao.txt). Ela nao substitui a captura de tela exigida na entrega.

Selecione a linguagem **C** ao executar em um compilador online. Os testes locais usaram Zig/Clang 19.1.7 no Windows. Os comandos acima sao para GCC.
