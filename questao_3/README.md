# Questao 3 - Substituicao de paginas FIFO

## Executar

Abra o terminal nesta pasta e execute:

```powershell
javac Questao3.java
java Questao3
```

Quando solicitado, informe 3 frames e a sequencia:

```text
7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2
```

## Resultado

Com a entrada de exemplo: 10 faltas, 3 acertos e taxa de 76,92%.

A saida real do teste esta em [resultado_execucao.txt](resultado_execucao.txt). Ela nao substitui a captura de tela exigida na entrega.
